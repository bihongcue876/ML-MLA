## 答辩备查

| 问题 | 建议回答 |
| --- | --- |
| 为什么我们的MLA PPL比MHA高？ | 当前简化实现和固定预算下，均值10.4368对9.14015，高约14.19%。联合低秩共享约束、实现差异和训练配方是可能原因，尚未消融分离；详见技术稿§4.2。不能说成准确率下降14.19%，或MLA必然损失质量。 |
| 继续训练就会追平吗？ | 留存汇总曲线到终点仍下降，说明尚不能把终点当各结构最好水平；也不能保证加训练量就追平。 |
| 是矩阵吸收让PPL下降吗？ | 这组质量数据对应恢复K/V的主模型；吸收计时是另一项实验，不能互相归因。 |
| 层级计时是否同权重同输入？ | 小FP32等价检查是；实际BF16计时重新初始化实例，并独立生成随机输入，控制的是结构参数与输入形状。 |
| c共享，各头会一样吗？ | 各头查询与上投影不同，权重和输出可以不同；共享的是历史信息来源。 |
| 能直接把任意MHA无损压成MLA吗？ | 不能保证。低秩是训练结构约束，现有模型转换还需适配和质量验证。 |
| RMSNorm一定破坏吸收吗？ | 取决于位置。潜变量先归一化后，上投影仍线性；展开后逐头K归一化不能直接吸收到同一固定线性变换。 |
| 为什么本实验没有论文5.76倍加速？ | 论文比较完整模型与服务系统，含MoE、量化、更大batch、8张H800；我们的batch1独立层时延是另一指标。 |
| 测32K就是能理解32K吗？ | 独立层使用随机隐向量，只测计算；主模型训练长度512，未评测32K语言能力。 |
| 4060能快多少？ | 未重测，不能给数字。元素公式不依赖显卡型号，实际时延依赖硬件和内核。 |
| 为什么不重跑全部任务？ | 本次整理技术讲解和已有结果，统计可离线复算；旧数据保留历史归属。新增性能或因果结论需要对应实验，不是文档PR的前置条件。 |

PPL差异的详细依据、未经验证的假设与后续可选实验，见[技术稿§4.2](mla_technology_report.md#42-质量参照)。
